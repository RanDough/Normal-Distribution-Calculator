# Normal Distribution Calculator

This was my very first actual python project I made for a school innovation contest back in the days. 
As you can see it very repetitive and is fully running on if, then statements.
It may be very very poorly written but it works like a charm. It was the first thing I did while still learning how to code and is actually how I learnt python in the first place.

## Features
- **Z and X Distribution Support:** Compute upper, lower, two-tailed, and interval probabilities [P(Z>a), P(|Z|>a), P(a<X<b), etc.].
- **Rendered Equations:** Displays the step-by-step methodology to obtain the final answer.
- **Graph Shading:** Displays a graph with shaded areas to visualise the distribution.

## Installation
```bash
git clone https://github.com/RanDough/Normal-Distribution-Calculator.git
cd Normal-Distribution-Calculator
pip install -r requirements.txt
```

## Usage
```python
python ND.py
```

## Requirements
- Python 3.6+
- numpy
- matplotlib
- tkinter
- scipy
